File class in Java:
===================


--File class is used to know the characteristics of something present in the harddisk.

--this class belongs to java.io package.


--The java.io.File class has many functinality which are used to identify the features/properties of a file or folder present in given location.

--File class object does NOT store file data, It only stores:

Path
Metadata





Example:


	File f=new File("abc.txt");


--The above line will not create any physical file.

--If that file is already exist then f will point to that file.

--if that file is not exist then it won't create a new file and here f simply represent name of the file.


Example:



System.out.println(f.exists()); //false..

f.createNewFile(); // creates a new File inside the current location.

System.out.println(f.exist()); //true




Note: A file Object can be used to represent a directory (folder) also.

Example:


File f=new File("myfolder");


System.out.println(f.exists());//false.


f.mkdir(); //create a new folder inside the current location.

System.out.println(f.exists()); //true






File class constructor:
-----------------------

1. File f=new File(String path); //Direct path to the file/folder.	

Example:

new File("C:/data/test.txt"): // absolute path

new File("test.txt"): // relative path



2. File f=new File(String subdir,String fname);

Example:

new File("C:/data", "test.txt")


3. File f=new File(File subdir,String fname);

--Uses an existing File object as the parent.

Example:

File f2 = new File("myDir"); // representing a directory


new File(f2, "test.txt");

IO Streams:
===========



Stream:
--------

--A stream is an abstraction that represents a flow of data from a source to a destination.

--Here the flow of data is in between the program and peripheral (devices)hence the name I/O Stream.

--So in Java programming whenever we need to make a data transfer we use Streams.


In Java, a stream is an abstraction used to read/write data between:

Program <-> File
Program <-> Memory
Program <-> Network
Program <-> Device



--in Java all classes using which we make the data transfer are present in java.io and java.nio package.


--For data transfer to be done first of all the data should be represented in its low-level equalivent i.e either in the form of bytes(8-bit) or in the form of charecters(16-bits).



--Depending upon the representation of the data to be transfered,The classes in the java.io package are classified into two categories:


1.Byte Oriented Classes
2.Charecter Oriented Classes.

--These two classes further divided into two categories 

1. Classes using which we can read the data.
2. Classes using which we can write the data.   


---InputStream class is the super class of all the classes using which we can read the data from source in the form of bytes.

---OutputStream class is the super class of all the classes using which we can write the data to the destination in the form of bytes.

---Reader class is the super class of all the classes using which we can read the data from source in the form of Chaerecters.

---Writer class is the super class of all the classes using which we can write the data to the destination in the form of Cherecters.


--The source and destination may be a file, an array, console,peripheral device or socket..


refer: IO_Stream_classes.jpg





Note:-If the last part of the name of the class is Stream then we can say that it is byte oriented class.
Example:DataInputStream,FileInputStream,PrintStream, etc.

--If the last part of the name of the class is Reader/Writer then we can say that given class is CharecterOriented class
Example:BufferdReader, FileWriter..etc.

---This may not be 100% true always.



----Whenever,it is required to transfer the data,then we should mention from where to where the transfer is to be made,ie we should mention the address of the source and destination.




Q/- How can we represent the address ?


A/- By creating object of these classes which contains the address of the source and destinations.

like, 

InputStream class object is used to represent address of the source. 
OutputStream class object is used to represent address of the destination,by using which we can trannsfer the data in the form of bytes.

simmillarly,

Reader class object is used to represent address of the sourse and Writer class obj is used to represent addesss of the destination,by using which we can transfer data in the form of charecter.

FileWriter:
-----------


---By using this class we can write charecter data ot the file.

FileWriter fw=new FileWriter(String filename);
FileWriter fw=new FileWriter(String filename,boolean flag); //append mode

or

FileWriter fw=new FileWriter(File f);
FileWriter fw=new FileWriter(File f,boolean flag);

Note: If the specified file is not available then above constructor will create a new file.


Methods of the FileWriter:
--------------------------

1. write(int ch): To write a single character to the file.

2. write(char ch[]): To write an array of charecter to the file.

3. write(String s): to write a string to the file.

4. flush(): to give the guarantee that last charecter of data also added to the file.

5. close(): to close the current opened file.



Note: The main limitation of the FileWriter is while writing the data we have to insert line-seperator..("\n")..or("\r\n")
and this line-seperator is varied from os to os.


Example:


Demo.java:
----------


package com.chitkara;

import java.io.FileWriter;
import java.io.IOException;

public class Demo {

	public static void main(String[] args) throws IOException {

		FileWriter fw = new FileWriter("abc.txt", true);

		fw.write(100);// d will be added
		fw.write("ramesh\nwelcome");
		fw.write("\n");
		fw.write("Odissa");
		char ch[] = { 'a', 'b', 'c' };
		fw.write(ch);
		fw.write("\n");
		fw.flush();
		fw.close();
	}

}

BufferedWriter:
===============


--We can use BufferedWriter class to write charecter data to the file.


Note: BufferedWriter class never communicate directly with the file. It communicate via some Writer object.

syntax:

	BufferedWriter bw=new BufferedWriter(Writer w);

Example:

	BufferedWriter bw=new BufferedWriter(new File("abc.txt")); //error

	BufferedWriter bw=new BufferedWriter("abc.txt"); //error


	BufferedWriter bw=new BufferedWriter(new FileWriter("abc.txt")); //ok


Methods of the BufferedWriter class:
------------------------------------



write(int ch): To write a single character to the file.

write(char ch[]): To write an array of charecter to the file.

write(String s): To write a string to the file.

flush(): To give the guarantee that last charecter of data also added to the file.

close(): To close the current opened file..

newLine(); To insert line seperator,it is independent to os.


Example:


Demo.java:
----------

package com.chitkara;

import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class Demo {

	public static void main(String[] args) throws IOException {

//		FileWriter fw = new FileWriter("abc.txt", true);
//
//		BufferedWriter bw = new BufferedWriter(fw);

		BufferedWriter bw = new BufferedWriter(new FileWriter("abc.txt", true)); // chaining mechanism

		bw.write(100);// d will be added
		bw.newLine();
		char ch[] = { 'a', 'b', 'c' };
		bw.write(ch);
		bw.newLine();
		bw.write("ramesh\nwelcome");

		bw.flush();
		bw.close();
	}
}

BufferedReader:
==============

--With the help of BufferedReader we can read the data from the file.

--The main advantage of BufferedReader over the FileReader is we can read the data line by line instead of charecter by charecter.

--Internally performance is better.

--BufferedReader can't communicate directly with the file, It will communicate with file via some Reader object.


Syntax:

	BufferedReader br=new BufferedReader(Reader r);


Example:

	BufferedReader br=new BufferedReader(new FileReader("a2.txt"));



Methods of the BufferedReader:
------------------------------



int read();

int read(char ch[]);

void close();

String readLine();//it attempts to read the next line from the destination. If the next line is not available it returns null value.


Example:


Demo.java:
----------



package com.chitkara;

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class Demo {

	public static void main(String[] args)  {

		try (BufferedReader br = new BufferedReader(new FileReader("abc.txt"))) {

			String line = br.readLine();

			while (line != null) {
				System.out.println(line);
				line = br.readLine();
			}

		} catch (IOException e) {

			e.printStackTrace();
		}

	}
}




Note: we can avoid the redundent code br.readLine() using the following approach: (recommended way)


String line;

while((line = br.readLine()) != null){

	System.out.println(line);
}

--But with the help of PrintWriter we can write any type of primitive data to the file.

Note: PrintWriter can communicate directly to the file and even via some writer object also.


PrintWriter pw=new PrintWriter(String fname);

PrintWriter pw=new PrintWriter(File f);

PrintWriter pw=new PrintWriter(Writer w);

PrintWriter pw=new PrintWriter("a1.txt"); // OK

FileInputStream Class:
----------------------

FileInputStream is used to read data from a file in byte form.

It is commonly used for:

Images
Videos
Audio files
Binary files


Reading data from a file using a byte oriented class:
-----------------------------------------------------


Note: read() method returns -1 when no more data is available which represents End of File (EOF) . 



Example:


Demo.java:
----------

package com.chitkara;

import java.io.FileInputStream;
import java.io.IOException;

public class Demo {

	public static void main(String[] args) {

		try (FileInputStream fis = new FileInputStream("abc.txt")) {

			int i = 0;

			while ((i = fis.read()) != -1) {
				System.out.print((char) i);
			}

		} catch (IOException e) {
			System.out.println(e.getMessage());

		}

	}
}


--The above example will works for normal english text(ASCII) but it will fails for Unicode. 

--So the FileInputStream is basically used to read the byte oriented files like images, audios, videos.where as FileReader and BufferedRead is used for reading the character oriented files like a text files, which can handles the Unicode internally.

BufferedInputStream Class:
--------------------------


--BufferedInputStream improves the performance of reading operations.

--It internally uses a memory buffer.

--Instead of reading one byte at a time from the file, it reads a large block of bytes at once into memory.

--This reduces the number of direct file access operations.


Real-Life Analogy of BufferedInputStream:
=========================================

--Imagine you need water from a water tank.

Without Buffer

--You go to the tank every time you need one glass of water.

--Very slow.

With Buffer

--You fill a bucket once and use water from the bucket repeatedly.

--Much faster.


Example:
--------

package com.chitkara;

import java.io.BufferedInputStream;
import java.io.FileInputStream;
import java.io.IOException;

public class Demo {

    public static void main(String[] args) {

        try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("abc.txt"))) {

            int i;

            while ((i = bis.read()) != -1) {
                System.out.print((char) i);
            }

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}



Advantages of BufferedInputStream
==================================

--Faster reading
--Reduces disk access
--Improves performance
--Efficient for large files







BufferedOutputStream Class:
----------------------------

--BufferedOutputStream improves writing performance using buffering.

--Instead of writing every byte directly to the file, data is first stored inside a buffer memory.

--When the buffer becomes full (or flush is called), data is written to the file together.


Example:


package com.chitkara;

import java.io.BufferedOutputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class Demo {

    public static void main(String[] args) {

        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("abc.txt"))) {

            String data = "Hello Java";

            bos.write(data.getBytes());

           
            System.out.println("Done");

        } catch (IOException e) {
           System.out.println(e.getMessage());

        }
    }
}


Advantages of BufferedOutputStream:
-----------------------------------

--Faster writing
--Reduces file access operations
--Improves efficiency
--Best for large data writing

Serialization:
==============

--Serialization is the process of converting an object (in RAM) into a byte stream so that it can be:

--Stored in a file.
--Sent over a network

--Object (RAM): -> Byte Stream:->  File / Network


--Using Serialization, we can transfer the state of an object from the RAM to the storage device or over a network.


Real-Life Analogy:
-----------------

--Think of it like packing luggage:

Object = Clothes
Serialization = Packing
File = Suitcase

--You convert object into a form that can be transported.


Serialization is Used when:
---------------------------

--Saving object data to file (backup)

--Sending data over network (client-server)

--Caching objects




Deserialization:
----------------

--Deserialization is the reverse process:

--From the Byte Stream to the Object (RAM)


Analogy:

--Like unpacking luggage.

File: Open suitcase
Data: Restore original object.




Note: We can't convert object of all classes to the byte stream to transfer it to another location outside the RAM.


--There is an interface by name Serializable belongs to java.io package:


	java.io.Serializable

--This interface is a marker or tag interface, which does not have any methods.


--Object of classes which implements the Serializable interface only are eligible for serialization. (Only they have the permission to be serialized).


--If we try to serialize a non-serializable object, we will get a runtime exception called NotSerializableException.


--The java.io.ObjectOutputStream class helps us in transfering the object of classes from our program(RAM) to the other location(network or harddisk): (Serialization)

--Similarly,the java.io.ObjectInputStream class helps us in transferring the object of classes from other location(network or harddisk) to our program(RAM)..(Deserialization)


--The object of ObjectOutputStream and ObjectInputStream class holds the address of source or destinations.

--We can serialize mutiple objects but in which order we serialized the objects, in the same order only we have to deserialized those objects.



---ObjectOutputStream class has a method by name:

 void writeObject(Object o);

--It takes the object of a class which implements the Serializable interface.



**Note: String class, all Wrapper classes, arrays, and most of the Collection framework classes implement the Serializable interface in Java.




Example:

-------

Deserialization:
================


--With the help of ObjectInputStream class, we can read back the object into the RAM, which we have serialized. This process is known as De-serialization.


Inside the ObjectInputStream class we have a method called:


Object readObject();

--Using this method we can deserailize the object in the form of object of Object class.

--To get back the actual objects we need to downcast the object of Object class into object of original class.

--For this we need to know the order(sequence) in which object were serialized, we need to deserialize the objects in the same order in which they are serialized.


Note: Here generics concept is not applicable.


**Note: While deserialization the constructor of the class will not be executed.

--During deserialization JVM does not create the object using constructor. Instead JVM internally recreates the object directly from byte stream data.



Example:


ReadDemo.java:
-------------



package com.chitkara;

import java.io.IOException;
import java.io.ObjectInputStream;

			Object obj = ois.readObject();

			A a1 = (A) obj;

			a1.funA();

			String message = (String) ois.readObject();

			System.out.println(message);

			int x = (Integer) ois.readObject();

			System.out.println(x);

		} catch (Exception e) {
			e.printStackTrace();
		}

	}

}




Note:  Even though we can serialize different types of object using the writeObject() method, but we should write homogenious type of object only, because at the time of deserialization we should know the sequence of serailized object which may cause the ClassCastException.

-----------------

--It is a unique version ID used inside the class, during serialization and deserialization.

private static final long serialVersionUID = 1L;



Meaning: 

serialVersionUID = Version number of a class


When an object is serialized, Java stores:

--Object data (state) 
--Class version (serialVersionUID)


During deserialization:

--JVM checks if class version matches If Not Matching it generates a InvalidClassException.


Real-Life Analogy:

--File saved with version 1
--Trying to open with version 2

--Prevents unexpected exceptions

transient Keyword in Java:
-------------------------


--transient is a keyword used with instance variables to indicate that:

-This variable related value should NOT be saved during serialization.

transient = "Do not serialize this variable" (Ignore this variable related value during serialization)


Syntax:

 transient int j = 20;


--At the time of serialization: JVM ignores original value of j.

--transient variables are NOT serialized. They get default values after deserialization.



Real-Life Analogy:
-----------------

Think of filling a form:

Name: saved 
Address: saved
Password: NOT saved 

--Here Password should be the transient field.


Common reasons:

--Security (passwords, OTPs)
--Temporary data (cache, session info)
--Derived/calculated values




transient vs static:
--------------------

--The static variables are not part of objects, they are the part of class, hence they will also not participate in serialization. 
--static value will be reloaded at the time of class loading time.

--So even we make a static variable as transient also, there will be no any effect.

Object Graph:

		// return studentList;

		return new ArrayList<>(studentList);
	}

	public Student searchStudentByRoll(int roll) {
		for (Student s : studentList) {

			if (s.getRoll() == roll) {

				return s;
			}
		}

		return null;
	}

	public boolean updateStudentMarks(int roll, double newMarks) {
		Student s = searchStudentByRoll(roll);

		if (s != null) {

			s.setMarks(newMarks);

			saveStudentsToFile();

			return true;
		}

		return false;
	}

		if (sortBy.equalsIgnoreCase("marks")) {
			Collections.sort(studentList, (s1, s2) -> Double.compare(s1.getMarks(), s2.getMarks()));

		} else if (sortBy.equalsIgnoreCase("roll")) {

		}

		for (Student s : studentList) {

		}

	}

	private void saveStudentsToFile() {

StreamTokenizer in Java:
========================


--StreamTokenizer is a class present in the java.io package.

--It is used to read data from a stream and automatically break it into smaller units called tokens.

These tokens can be:

Words
Numbers
Symbols
Special characters
End of line
End of file



--It helps us identify whether the current data is a:

word
number
symbol

without manually splitting strings.




Real-Life Analogy: 
-----------------

--Suppose a teacher gives you the following sentence:

	Java is easy 100 times

--You naturally divide it into parts:

Java
is
easy
100
times

--Each separated part is called a token.

--StreamTokenizer does the same work automatically.


Q/- Why Do We Need StreamTokenizer?


A/- Normally when reading data from a file:


FileReader fr = new FileReader("data.txt"); // reads character by character

//OR

BufferedReader br = new BuffererdReader(new FileReader("data.text")); // reads line by line


But sometimes we want:

--words separately
--numbers separately
--symbols separately

Doing this manually is difficult.

StreamTokenizer simplifies this work.



Constructor:
------------

StreamTokenizer st = new StreamTokenizer(Reader obj);


Example1:

FileReader fr = new FileReader("data.txt");
StreamTokenizer st = new StreamTokenizer(fr);


Example2:

BufferedReader br = new BufferedReader(new FileReader(data.txt));
StreamTokenizer st = new StreamTokenizer(br);


Important Fields of StreamTokenizer class:
-------------------------------------------

int ttype; // Stores the type of the current token.

String sval; // Stores the string value if the token is a word.

double nval; // Stores the numeric value if the token is a number.






Important Constants of StreamTokenizer class:
---------------------------------------------

StreamTokenizer.TT_EOF; // Represents End Of File.
StreamTokenizer.TT_EOL; // Represents End Of Line.
StreamTokenizer.TT_NUMBER; // Represents a numeric token.
StreamTokenizer.TT_WORD; // Represents a word token.




Important Method:
-----------------

int nextToken()

--This method reads the next token from the stream.




Example:

File Content (data.txt)
-----------------------

Java 100 Python 200



Demo.java:
----------


package com.chitkara;

import java.io.FileReader;
import java.io.StreamTokenizer;

public class Demo {

	public static void main(String[] args) {

		try (FileReader fr = new FileReader("data.txt")) {

			StreamTokenizer st = new StreamTokenizer(fr);

			while (st.nextToken() != StreamTokenizer.TT_EOF) {

				if (st.ttype == StreamTokenizer.TT_WORD) {
					System.out.println("Word :" + st.sval);
				}

				else if (st.ttype == StreamTokenizer.TT_NUMBER) {
					System.out.println("Number :" + st.nval);
				}

			}

		} catch (Exception e) {
			System.out.println(e.getMessage());
		}

	}
}


Output:

Word : Java
Number : 100.0
Word : Python
Number : 200.0

Configuring the StreamTokenizer:
---------------------------------

--StreamTokenizer allows customization of token parsing behavior.


1. eolIsSignificant(boolean flag): 

--If true, newline characters are treated as tokens (TT_EOL).

Useful when processing:

CSV files
line-based commands
expressions line-by-line




2. slashSlashComments(boolean flag): 

--If true, recognizes // and ignores everything until the end of the line.

Example:


File Content (data.txt):
------------------------

Java 100 // This is Java marks
Python 200

------

st.ordinaryChar('/'); // this / has internal meaning, to tell it is an ordinary char.

    }

    }else {
	System.out.println("SYMBOL : " + (char) st.ttype);
    }

}

200.0

--The comment part is ignored.



3. slashStarComments(boolean flag): 

--If true, recognizes /* ... */ and ignores the content. (multiline comments)

Example:

File Content(data.txt):
-----------------------

Python 200


st.slashStarComments(true);


Output:

100.0
Python
200.0



4. whitespaceChars(int low, int hi): 


--Treats characters in the specified range as whitespace.

--These characters become separators and are ignored.

Example: Treating Comma as Whitespace (separator)


File Content(data.txt):
-----------------------

st.whitespaceChars(',', ',');

5. wordChars(int low, int hi):

--It forces a range of characters to be treated as part of words.

Useful for:

email parsing
usernames
special identifiers

By default:

--To treat it as a single word:

6. quoteChar(int ch)

--Treats text inside quotes as a single token.


Example:

File Content(data.txt):

Limitations:

package com.chitkara;

import java.io.FileReader;
import java.io.StreamTokenizer;

public class Demo {

    public static void main(String[] args) {

        try (FileReader fr = new FileReader("data.txt")) {

            StreamTokenizer st = new StreamTokenizer(fr);

            // Treat ':' and ',' as separators
            st.whitespaceChars(':', ':');
            st.whitespaceChars(',', ',');

            String studentName = "";
            double highestMarks = Double.MIN_VALUE;
            String topper = "";

                if (st.ttype == StreamTokenizer.TT_WORD) {

                    // Read Marks
                    st.nextToken();

                    if (st.ttype == StreamTokenizer.TT_NUMBER) {

                        if (marks > highestMarks) {
                            highestMarks = marks;
                            topper = studentName;
                        }
                    }
                }

Q2/- Print the Poem with Stars:



--Implement the following method:


	printPoemWithStars(String fileName, int width)

The method should:

--read a text file line by line,
--print each line inside a box made of * characters,
--and display a border on all four sides.

Requirements:

--Convert each line into title case:
	first letter uppercase
	remaining letters lowercase

--The second parameter (width) represents the total width of the box including borders.

--If a line is longer than the available space, truncate it.

--If a line is shorter, add spaces so that all lines fit properly inside the box.

Example:

Input File: (poem.txt)
-----------

Johny Johny
Yes papa
Eating sugar


call the method:
----------------

	printPoemWithStars(poem.txt, int 19);




Output:
--------

*******************
*Johny johny      *
*Yes papa         *
*Eating sugar     *
*******************





Solution approach:
------------------


1. print the boder of stars with exact width(19) at the top and bottom (first line and last line)


*******************


2. print * to the left and right.

*Hello           *


3. Title case conversion:

if line is:

	hello chitkara

then, convert it as 


	Hello chitkara

--First chararcter upper case and remaining in lowercase



4. Padding spaces:

--If the line is shorter than width-2 then add extra spaces. so that width should be fixed.


5. truncate the long lines:


--If the line is too long (longer than width - 2 then  trim the line and print only the fitting characters)



Example:
---------


package com.chitkara;

import java.io.BufferedReader;
import java.io.FileReader;

public class Demo {

    public static void printPoemWithStars(String fileName, int width) {

        int textWidth = width - 2;

        // print top border
        for (int i = 1; i <= width; i++) {

            System.out.print("*");
        }

        System.out.println();

        try (BufferedReader br = new BufferedReader(new FileReader(fileName))) {

            String line;

            while ((line = br.readLine()) != null) {

                // convert to title case
                line = convertToTitleCase(line);

                // truncate if too long
                if (line.length() > textWidth) {

                    line = line.substring(0, textWidth);
                }

                // print left border
                System.out.print("*");

                // print text
                System.out.print(line);

                // remaining spaces
                for (int i = line.length(); i < textWidth; i++) {

                    System.out.print(" ");
                }

                // right border
                System.out.println("*");
            }

        } catch (Exception e) {

            e.printStackTrace();
        }

        // print bottom border
        for (int i = 1; i <= width; i++) {

            System.out.print("*");
        }

        System.out.println();
    }

    // helper method
    public static String convertToTitleCase(String str) {

        if (str.length() == 0) {

            return str;
        }

        String first = str.substring(0,1).toUpperCase();

    	String remaining = str.substring(1).toLowerCase();

    	return first + remaining;
    }

    public static void main(String[] args) {

        printPoemWithStars("poem.txt", 19);
    }
}
