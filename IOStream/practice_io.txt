Q/- Write a program to read a html file and read all the text wrapped between the tags:



File content (data.txt)
------------------------

<p>Hello Java</p>
<h1>Welcome to Chitkara</h1>




Output:
-------

Hello Java
Welcome to Chitkara






Solution: approach
-------------------

--Read the file character by character

-- ignore from '<' to '>'

--print the remaining text.




Demo.java:
-----------


package com.chitkara;

import java.io.FileReader;

public class Demo {

	public static void main(String[] args) {

		boolean insideTag = false;

		try (FileReader fr = new FileReader("data.txt")) {

			int ch;

			while ((ch = fr.read()) != -1) {

				// tag starts
				if (ch == '<') {

					insideTag = true;
				}

				// tag ends
				else if (ch == '>') {

					insideTag = false;
				}

				// print only text outside tags
				else if (insideTag == false) {

					System.out.print((char) ch);
				}
			}

		} catch (Exception e) {

			e.printStackTrace();
		}
	}

}



Q2/- Print the Poem with Stars:



--Implement the following method:


	printPoemWithStars(String fileName, int width)

The method should:

--read a text file line by line,
--print each line inside a box made of * characters,
--and display a border on all four sides.

Requirements:

--Convert each line into title case:
	first letter uppercase
	remaining letters lowercase

--The second parameter (width) represents the total width of the box including borders.

--If a line is longer than the available space, truncate it.

--If a line is shorter, add spaces so that all lines fit properly inside the box.

Example:

Input File: (poem.txt)
-----------

Johny Johny
Yes papa
Eating sugar


call the method:
----------------

	printPoemWithStars(poem.txt, int 19);




Output:
--------

*******************
*Johny johny      *
*Yes papa         *
*Eating sugar     *
*******************





Solution approach:
------------------


1. print the boder of stars with exact width(19) at the top and bottom (first line and last line)


*******************


2. print * to the left and right.

*Hello           *


3. Title case conversion:

if line is:

	hello chitkara

then, convert it as 


	Hello chitkara

--First chararcter upper case and remaining in lowercase



4. Padding spaces:

--If the line is shorter than width-2 then add extra spaces. so that width should be fixed.


5. truncate the long lines:


--If the line is too long (longer than width - 2 then  trim the line and print only the fitting characters)



Example:
---------


package com.chitkara;

import java.io.BufferedReader;
import java.io.FileReader;

public class Demo {

    public static void printPoemWithStars(String fileName, int width) {

        int textWidth = width - 2;

        // print top border
        for (int i = 1; i <= width; i++) {

            System.out.print("*");
        }

        System.out.println();

        try (BufferedReader br = new BufferedReader(new FileReader(fileName))) {

            String line;

            while ((line = br.readLine()) != null) {

                // convert to title case
                line = convertToTitleCase(line);

                // truncate if too long
                if (line.length() > textWidth) {

                    line = line.substring(0, textWidth);
                }

                // print left border
                System.out.print("*");

                // print text
                System.out.print(line);

                // remaining spaces
                for (int i = line.length(); i < textWidth; i++) {

                    System.out.print(" ");
                }

                // right border
                System.out.println("*");
            }

        } catch (Exception e) {

            e.printStackTrace();
        }

        // print bottom border
        for (int i = 1; i <= width; i++) {

            System.out.print("*");
        }

        System.out.println();
    }

    // helper method
    public static String convertToTitleCase(String str) {

        if (str.length() == 0) {

            return str;
        }

        String first = str.substring(0,1).toUpperCase();

    	String remaining = str.substring(1).toLowerCase();

    	return first + remaining;
    }

    public static void main(String[] args) {

        printPoemWithStars("poem.txt", 19);
    }
}
